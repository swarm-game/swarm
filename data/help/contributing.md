% title: Contributing
% author: Brent Yorgey

Interested in [contributing to Swarm](https://github.com/swarm-game/swarm/blob/main/CONTRIBUTING.md)?  All are welcome!

- The documents in this help system are all written in [Markdown
  format (with a few extensions)](markdown), in the
  [`data/help`{=snippet}](https://github.com/swarm-game/swarm/tree/main/data/help)
  folder.  You can help contribute new documentation, or improve
  existing documentation, even if you don't know any Haskell.
